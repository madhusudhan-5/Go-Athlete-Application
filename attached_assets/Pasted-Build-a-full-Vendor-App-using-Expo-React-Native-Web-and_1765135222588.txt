Build a full Vendor App using Expo (React Native + Web) and Django REST API backend.

GOALS:
Vendor application with 3 types of vendor users:
1) Venue owner / Court owner
2) Coach / Trainer
3) Sports E-commerce Vendor

These 3 types can register and login inside the Vendor app. When a vendor is a venue owner:
- They can manage all their venues, courts, coaches, products.
- They can also personally book courts for walk-in customers and collect cash or online later (placeholder).
Coaches only see coaching screens.
Ecommerce vendors only see product screens.

REGISTRATION & LOGIN
Vendor registration MUST be available on the app:
- minimal data:
  owner name
  business/entity name
  phone
  email
  PAN / Aadhaar (min any 2 ID proofs upload)
  business type (VENUE, COACH, ECOM or combination)
  license/registration proof upload
Validation is required: phone, email, 2 IDs mandatory.
After registration, vendor enters the app with “pending” status until approved by admin/super-admin (future integration; just status field for now).
Login continues same email+password logic.
