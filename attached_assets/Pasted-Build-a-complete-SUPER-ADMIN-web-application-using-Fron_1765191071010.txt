Build a complete SUPER ADMIN web application using:

Frontend: React (web, responsive)
Backend: Django REST Framework
Design System: Material Design 3 (MD3)
Color palette:
  primary: #0A1F35
  secondary: #DA6F2B
  darkPrimary: #030929
Light + Dark mode toggle, persist preference
Responsive for desktop/tablet/mobile

The SUPER ADMIN is the TOP MOST ROLE:
- SUPER ADMIN manages platform level controls
- SUPER ADMIN creates and manages Admins
- SUPER ADMIN configures global settings
- SUPER ADMIN has visibility to all vendors, bookings, payouts, commissions, offers, products
- SUPER ADMIN overrides ADMIN permissions
- SUPER ADMIN manages entire system security and operations

=================================================================
AUTH & ROLE MODEL (SUPER ADMIN)
=================================================================
Separate login endpoint:
POST /api/super/auth/login/

SUPERAUTH model:
SuperAdmin:
  id
  email (unique)
  password
  full_name
  phone
  is_active
  created_at

SUPERADMIN actions include:
- Add Admin
- Edit Admin permissions
- Enable/Disable Admin accounts
Root role above everything else

Frontend:
- secure /super/* routes
- login at /super/login
- redirect unauthorized to login
- store JWT token
- MD3 protected layout

=================================================================
ADMIN MANAGEMENT (BY SUPER ADMIN)
=================================================================
SUPER ADMIN can create and modify Admin accounts and permissions:

Model:
AdminUser:
  id
  email
  password (hashed)
  full_name
  phone
  is_active
  permissions:
    can_manage_vendors
    can_manage_commissions
    can_manage_offers
    can_manage_bookings
    can_manage_tickets
    can_manage_reports
    can_manage_memberships
    can_manage_payouts

Endpoints:
- GET /api/super/admins/
- POST /api/super/admins/
- GET /api/super/admins/:id/
- PATCH /api/super/admins/:id/
- POST /api/super/admins/:id/enable/
- POST /api/super/admins/:id/disable/

UI:
Route: /super/admins
List admins with status badges
Actions:
  Add New Admin → MD3 dialog with fields + permissions toggles
  Edit Admin → modify permissions
  Enable/Disable account
Validation:
Email unique
Password strong policy optional

=================================================================
COMMISSION OVERRIDE & HISTORY
=================================================================
Super Admin can override commissions globally and view history:

Model:
CommissionHistory:
  id
  changed_by (SuperAdmin)
  court_pct
  coach_pct
  ecommerce_pct
  membership_pct
  changed_at

Endpoint:
- GET /api/super/commissions/history
- POST /api/super/commissions/override (new global values)

UI:
Route: /super/settings/commissions
- Current commission config read-only
- Override (if required)
- Show log/history table sorted by changed_at desc
Validation:
0–100 range
Show warning dialog “This affects entire platform”
